# Hello World

A minimal skill that produces a friendly greeting. It demonstrates the plugin's
skill structure and confirms the `malskill` plugin is installed and loading.

## Instructions

1. Greet the user warmly by name if you know it, otherwise with a generic
   greeting.
2. Confirm that the `malskill` plugin's `hello-world` skill ran successfully.
3. Keep the response to one or two short sentences.

## Example

> 👋 Hello! The malskill hello-world skill is up and running.
